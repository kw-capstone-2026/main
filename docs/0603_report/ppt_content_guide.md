# 📢 캡스톤 디자인 PPT 발표자료 제작용 AI/ML 핵심 요약서 (ppt_content_guide.md)

본 문서는 발표 자료(PPT 슬라이드)를 제작하는 팀원이 **그대로 복사하여 슬라이드 텍스트로 배치하고 발표 대본으로 삼을 수 있도록** 각 슬라이드별 핵심 구성안(Why-How-Result)을 정리한 가이드라인입니다.

## 💻 Slide 1: 데이터 불균형(Class Imbalance) 문제 해결

### 1. 슬라이드 제목

- **데이터 불균형(3%) 문제 해결을 위한 샘플링 및 가중치 비교 실험**

### 2. 슬라이드 텍스트 (Copy & Paste용)

- **[배경 (Why)]**
  - 서울시 상권 내 폐업/과포화 위험 점포 비율은 **단 3%**로 극심한 클래스 불균형 데이터셋입니다.
  - 일반적인 정확도(Accuracy) 지표는 다수 클래스(영업중 97%)를 단순히 찍기만 해도 왜곡되는 현상이 나타나므로, 소수 정밀 탐지를 평가할 **PR-AUC (Precision-Recall AUC)**를 핵심 학술 지표로 채택했습니다.
- **[해결 방법 (How)]**
  - 데이터 레벨 해결 (Resampling): **SMOTE (오버샘플링)**, **RUS (언더샘플링)**, **Hybrid (SMOTE+RUS)** 실험 진행.
  - 알고리즘 레벨 해결 (Cost-Sensitive): 원본 분포를 보존한 채 손실 함수의 패널티 가중치 비율을 조정한 **클래스 가중치(None, scale_pos_weight=33.33)** 실험 진행.
- **[비교 실험 성적표 (Result)]**
  - **SMOTE 단독 적용**: 표(Tabular) 데이터 변수 공간상의 과적합 노이즈로 오탐(False Positive)이 증가하여 PR-AUC가 **0.2422**로 급락.
  - **RUS 단독 적용**: 정상 데이터의 90% 이상이 손실되어 중요 정보 누락으로 PR-AUC가 **0.3031**로 하락.
  - **최종 채택 (None + 가중치 조정)**: 원본 데이터의 정보를 완전 보존하여 가장 우수한 **PR-AUC (0.3171)**를 기록하며 불균형 극복.

### 3. 발표자 대본 가이드 (Script)

> "저희 상권 데이터에서 실제 폐업 위험 점포는 단 3%뿐입니다. 이 3%를 정밀하게 분류하기 위해 저희 팀은 데이터 오버샘플링(SMOTE), 언더샘플링(RUS) 등 다양한 샘플링 기법을 돌려 직접 비교 실험을 수행했습니다. 검증 결과, 인공적인 데이터를 추가하는 SMOTE 방식은 표 데이터의 고유한 공간 구조를 파괴해 노이즈를 늘려서 PR-AUC가 0.24로 하락하는 부작용이 있었습니다. 이에 따라 원본 데이터를 100% 보존하면서 모델 내부적으로 손실 함수의 패널티 비중을 33.33배 늘려 소수 클래스를 강조하는 '비용 민감 가중치 조율' 방식을 최종 채택해 최상의 변별력(PR-AUC 0.3171)을 확보했습니다."

## 💻 Slide 2: AI/ML 앙상블 모델링 및 성능 고도화

### 1. 슬라이드 제목

- **XGBoost & LightGBM Soft Voting 앙상블 아키텍처 및 검증**

### 2. 슬라이드 텍스트 (Copy & Paste용)

- **[배경 (Why)]**
  - 단일 알고리즘 학습 시 발생할 수 있는 특정 피처에 대한 편향성(XGBoost의 전년 대비 폐업 증감률 과도 의존 등)을 극복하고 모델의 일반화(Generalization) 능력을 극대화하고자 하였습니다.
- **[아키텍처 설계 (How)]**
  - 정적 분류 경계를 강하게 규제하는 **XGBoost**와 리프 중심 성장을 통해 파생 밀도 변수의 유효성을 극대화하는 **LightGBM**을 결합.
  - 2019Q1~2023Q4(44만 행)를 학습용 데이터로 사용하고, **2024년 1~4분기 실제 전체 데이터(7.2만 행)를 최종 테스트 데이터**로 사용해 시계열 검증(Time-Series Split).
  - 예측 확률값에 대해 **XGBoost 0.3 : LightGBM 0.7** 비율의 가중치를 적용한 **Soft Voting 앙상블 Classifier** 최종 구축.
- **[모델별 성능 검증 결과 (Result)]**
  - 단일 XGBoost: ROC-AUC 0.9076 | PR-AUC 0.3135
  - 단일 LightGBM: ROC-AUC 0.9089 | PR-AUC 0.3170
  - **최종 앙상블 모델**: **ROC-AUC 0.9089 (최고) | PR-AUC 0.3171 (최고) | F1-Score 0.2361 (최고)** 돌파.

### 3. 발표자 대본 가이드 (Script)

> "단일 모델의 한계와 과적합을 방지하기 위해 저희는 XGBoost와 LightGBM을 결합한 Soft Voting 앙상블 기법을 설계했습니다. 2019년부터 2023년까지의 데이터를 학습하고 완전히 분리된 2024년 실제 상권 데이터를 통해 최종 시계열 테스트를 거쳤습니다. 검증 결과, 단일 모델 대비 앙상블 모델이 소수 클래스의 실질적 탐지력 지표인 PR-AUC 및 F1-Score에서 최고 성능을 갈아치우며, 실제 미시적 환경 변화에 매우 유연하고 안정적인 성능을 입증해 냈습니다."

## 💻 Slide 3: Log-odds 기반 위험 지수 (Risk Score) 산정 공식

### 1. 슬라이드 제목

- **금융 신용평가식(Log-odds) 기반의 직관적인 위험 지수(0~100점) 스케일링**

### 2. 슬라이드 텍스트 (Copy & Paste용)

- **[배경 (Why)]**
  - 인공지능이 계산한 폐업 확률값($p \in [0, 1]$)은 그 수치 자체로는 일반 창업 예정자나 비즈니스 매니저가 직관적으로 위험 수준을 판단하기 어렵습니다.
- **[공식 설계 (How)]**
  - 금융권의 FICO 신용 평점이나 Platt Scaling 방법론과 동일한 **Log-odds 기반의 Logistic Scaling 공식**을 설계.
  - **공식**:
    $$\text{log\_odds} = \ln\left(\frac{p}{1-p}\right)$$
    $$\text{Risk Score} = \text{Clip}\left(50 + 15 \times \text{log\_odds}, \ 0, \ 100\right)$$
  - 상권 평균 확률($p = 50.38\%$) 기준점을 **50점**으로 맵핑하고, 민감 계수를 15로 설정하여 극단값에서의 위험 구분을 정교화함.
- **[실제 점포 케이스 매핑 수치 (Result)]**
  - **고위험 점포 (Danger)**: 모델 확률 94.76% $\rightarrow$ **위험 지수 93점**
  - **저위험 점포 (Safe)**: 모델 확률 19.29% $\rightarrow$ **위험 지수 29점**
  - **평균 기준 점포 (Base)**: 모델 확률 50.38% $\rightarrow$ **위험 지수 50점**

### 3. 발표자 대본 가이드 (Script)

> "인공지능 모델이 내뱉은 0과 1 사이의 확률값은 최종 사용자가 직관적으로 이해하기 어렵습니다. 이를 해결하기 위해 저희 팀은 단순 100을 곱하는 1차원적인 매핑 대신, 금융권 신용평가 모델에서 리스크 점수를 맵핑할 때 보편적으로 활용되는 'Log-odds 기반 Logistic 스케일링' 수식을 직접 설계했습니다. 평균적인 상권 확률 지점을 딱 50점으로 고정하고, 위험도가 높은 구간과 낮은 구간의 편차를 log-odds 공간에서 정교하게 변별함으로써, 실제 폐업률 94.76%의 고위험 점포는 93점, 19.29%의 안전 점포는 29점으로 매핑하는 정밀한 평가 체계를 갖추었습니다."

## 💻 Slide 4: 설명 가능한 AI (SHAP XAI) 기반 1:1 리스크 진단

### 1. 슬라이드 제목

- **SHAP 시각화와 위험 임계점(Tipping Point) 기반의 1:1 맞춤형 처방**

### 2. 슬라이드 텍스트 (Copy & Paste용)

- **[배경 (Why)]**
  - 머신러닝의 블랙박스 문제를 해소하고, 개별 점포의 점수 산출 원인을 투명하게 설명하기 위해 XAI(SHAP) 기술을 도입하였습니다.
- **[로컬 해석 시나리오 (How)]**
  - **고위험 점포 (93점)**:
    - 핵심 악재: `전년 대비 폐업 증감률 = 2.0 (2배 폭증)` (SHAP $+2.18$), `점포당 평균 매출 = 91만 원 (최저)` (SHAP $+1.00$)
    - 위험 상승 원인: 상권의 폐업 폭증과 점포별 낮은 생산성이 최종 점수를 견인.
  - **저위험 점포 (29점)**:
    - 핵심 호재: `전년 대비 폐업 증감률 = 0.0 (안정)` (SHAP $-0.82$), `점포당 평균 매출 = 4,751만 원 (최우수)` (SHAP $-0.75$)
    - 위험 감소 원인: 상권의 안정성과 개별 점포의 압도적 매출 성과가 안전 마진 역할.
- **[위험 임계점(Tipping Point) 발견 (Result)]**
  - SHAP 의존성 분석을 통해, **분기 평균 매출이 1,500만 원~2,000만 원 선 이하로 떨어지면 폐업 리스크가 지수적으로 폭증**하는 물리적 임계점(Tipping Point)을 데이터로 최초 입증.

### 3. 발표자 대본 가이드 (Script)

> "마지막으로 저희 모형의 가장 큰 특징은 단순 점수 나열을 넘어, '왜 이 가게가 위험한지' 개별 점포 수준에서 1대1 맞춤형 진단이 가능하다는 점입니다. 고위험으로 판정된 점포의 경우 상권 내 폐업이 전년 대비 2배로 폭증한 악재와 함께, 점포당 평균 매출이 91만 원대에 불과한 점이 결정적인 리스크 상승 요인으로 분석되었습니다. 특히 저희는 SHAP 의존성 분석을 통해 분기 매출 1,500만 원, 즉 월평균 약 500만 원 수준을 생존을 유지하기 위한 일종의 '위험 임계 마지노선(Tipping Point)'으로 잡아냈습니다. 매출이 이 선 밑으로 꺾이면 주변 매출 밀도가 낮은 상권일수록 위험도가 기하급수적으로 폭발하게 됨을 통계학적으로 입증해 내었습니다."
