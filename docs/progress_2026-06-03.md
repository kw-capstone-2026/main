### ② 데이터 전처리 (클래스 불균형 해결) 비교 실험
* **상태**: 완료 (`agenttest/run_sampling_experiments.py` 실행 완료)
* **결과**: 서울시 상권 폐업 비율(약 3%)의 극심한 불균형 상태를 다루기 위해 4가지 전처리 기법을 적용해 2024년 실제 테스트 데이터로 검증하였습니다.
  
| 전처리 기법 (Sampling) | 모델 구분 (Model) | ROC-AUC | PR-AUC (주 지표) | F1-Score | Accuracy |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **None (클래스 가중치만 부여)** | **Ensemble (XGB 0.3:LGB 0.7)** | **0.9089** | **0.3171** | **0.2361** | **0.8310** |
| **SMOTE (오버샘플링)** | Ensemble (XGB 0.3:LGB 0.7) | 0.8879 | 0.2422 | 0.3042 | 0.9132 |
| **Random Under-sampling (RUS)** | Ensemble (XGB 0.3:LGB 0.7) | 0.9064 | 0.3031 | 0.2294 | 0.8250 |
| **SMOTE + RUS (Hybrid)** | Ensemble (XGB 0.3:LGB 0.7) | 0.9013 | 0.2755 | 0.2571 | 0.8605 |

* **학술적 해석 (PPT용)**: SMOTE와 같은 오버샘플링 기법은 34차원 변수 공간에 가상 데이터를 과도하게 생성하여 노이즈를 늘리기 때문에, Precision이 낮아져 PR-AUC가 **0.24** 수준으로 크게 하락합니다. 반면 원본 데이터의 특성을 그대로 유지하며 비용 민감도(`scale_pos_weight`) 가중치 조정을 적용한 모델이 가장 우수한 **PR-AUC (0.3171)**를 보였습니다. 
* **산출물**: [sampling_experiment_results.md](file:///e:/capstone/kw-capstone-2026/agenttest/sampling_experiment_results.md) 생성 완료.

### ③ 위험 지수 (Risk Score) 산정 공식 수식화
* **상태**: 완료 (`agenttest/calculate_risk_score.py` 실행 완료)
* **결과**: 모델의 예측 확률값($p$)을 단순히 `0~100` 점수로 매핑하는 선형 매핑과, 금융권 신용평가에서 사용하는 **Log-odds 기반 Logistic Scaling 공식**을 설계하여 비교 계산을 수행했습니다.
  - **공식**: $\text{Score}_{\text{logistic}} = \text{Clip}(50 + 15 \times \ln(p / (1 - p)), \, 0, \, 100)$
  - **고위험 점포 (Danger Store, 확률 94.76%)**: 선형 95점 $\rightarrow$ **Log-odds 93점**
  - **저위험 점포 (Safe Store, 확률 19.29%)**: 선형 19점 $\rightarrow$ **Log-odds 29점**
* **학술적 해석 (PPT용)**: Log-odds 기반 스케일링은 극단적인 확률 구간에서도 미세한 위험도 편차를 log-odds 공간에서 넓게 펼쳐 변별력을 극대화하므로, 학술 논문 및 신용평가 모형 수준의 정밀한 지수 산정 근거가 됩니다.
* **산출물**: [risk_score_results.md](file:///e:/capstone/kw-capstone-2026/agenttest/risk_score_results.md) 생성 완료.
