1. 파이썬 마스터셋 -> Spring Boot PostgreSQL DB 일괄 적재

[현상태] 파이썬 ML 분석 단에서 앙상블 예측 및 SHAP 로컬 시각화 수치는 완벽하게 연산되어 있으나, Spring Boot JPA가 연동하는 PostgreSQL DB의 `predictions` 및 `shap_features` 테이블은 아직 빈 껍데기 상태입니다.

[핵심 도전 과제]
51.2만 행 대용량 Parquet 데이터셋에 대해 우리가 학습 완료한 Soft Voting 모델로 예측값과 SHAP Top5 피처 기여도 데이터를 **일괄적으로 뽑아낸 후, 이를 DB의 테이블 구조(`schema.sql`)에 맞춰 direct import(Bulk Insert)해 주는 마이그레이션 스크립트**가 부재하여 DB가 텅 빈 모순을 격파해야 합니다.

-- database/schema.sql 연계 타겟 테이블
CREATE TABLE IF NOT EXISTS predictions (
  block_id BIGINT REFERENCES blocks(id),
  csi_score NUMERIC(4,2),
  risk_grade VARCHAR(20),
  closure_rate NUMERIC(5,2),
  open_rate NUMERIC(5,2),
  survival_6m NUMERIC(5,2)
);

[해결책 - 마이그레이션 스크립트 작성] 6일의 마감 기간 내에 파이썬 단에서 **PostgreSQL Seed SQL/CSV 제너레이터**를 구현하여 DB에 대량의 분석 데이터를 적재하고, 리액트가 Spring Boot API를 통해 이를 1ms 내로 쿼리하도록 서빙 연결을 완수합니다.

2. React Mock UI -> 백엔드 실제 통신(Axios) 연동

[현상태] 리액트 프론트엔드의 화면 레이아웃과 Recharts 차트는 미려하게 그려져 있으나, 모든 수치와 그래프 값들은 `MOCK_SHAP` 등 하드코딩된 더미 JS 데이터로 구동되는 완벽한 Mock 상태입니다.

[핵심 도전 과제]
Spring Boot 백엔드의 엔드포인트(`/api/v1/blocks/{blockId}/prediction` 등)를 호출하여 DB의 진짜 예측/SHAP 기여 데이터를 받아와 Recharts 그래프에 동적으로 실시간 매핑해 주어야 합니다.

리액트 Axios 연동 아키텍처
  • API 주소: `/api/v1/blocks/{blockId}/prediction` 호출
  • 수치 데이터 바인딩: 폐업률, 개업률, 6개월 생존 확률, 리스크 점수 매핑
  • 차트 데이터 바인딩: `/shap` 호출 후 Recharts `BarChart`에 실시간 호재/악재 기여도 전달

[기대 효과] 더미 화면이 아닌, 실제로 DB 데이터베이스와 완벽히 동조되어 마커 클릭 즉시 실제 분석 결과를 보여주는 완벽한 풀스택 시연 서비스를 확보합니다.

Q1. 단순 절대치 변수의 한계를 극복한 '상대적 경쟁 밀도(Density)' 피처의 학술적 의의

"기존 시도들처럼 '유동인구 수', '매출 금액' 같은 단순 절대규모(절대치) 변수만 투입했을 때는 변수의 크기 편향으로 인해 AI 모델의 성능이 정체되었습니다. 저희가 이를 상권 내부의 실제 경쟁 압박으로 해석하기 위해 '점포당 매출 밀도', '유사업종 점포비율', '집객시설 밀도' 등 상대적 밀도(Density) 파생 변수들을 정교하게 설계하여 기여도 Top 10에 대거 진입시켰습니다. 이러한 사회과학적 경쟁 모델 관점의 피처 엔지니어링 방식이 졸업논문의 핵심 기여도로 충분한 가치를 가질지 교수님의 학술적 의견을 여쭙고 싶습니다."

Q2. 데이터 불균형(3%) 상황에서 PR-AUC(0.3171)를 주 지표로 제안하는 것에 대한 지도

"서울시 상권의 과포화/폐업 상점 비율은 전체의 3% 수준으로 클래스 불균형이 극심합니다. 일반적인 ROC-AUC(0.9089)는 단순히 정상 상권을 잘 맞추는 것으로 거품이 낄 수 있으므로, 저희가 소수 클래스의 실질적 탐지력인 PR-AUC (0.3171) 및 소수 F1-Score (0.2361)를 모델 평가의 최종 대표 지표로 논문과 PPT에 제시하여 정밀한 신뢰성을 증명하고자 하는데, 이에 대한 타당성 자문을 구합니다."

XGBoost + LightGBM 소프트 보팅 앙상블 상호보완형 AI 협동 예측 모델
"내과 전문의와 외과 전문의가 힘을 합쳐 투표로 최종 진단을 내리듯, 두 AI가 서로의 장단점을 보완해 예측 정확도를 극대화합니다."
수평적 트리 구조의 XGBoost와 수직적(리프 중심) 트리 구조의 LightGBM을 3:7 비율로 결합(Soft Voting)하여, 단일 모델의 특정 변수 편향성을 극복하고 일반화 성능을 극대화했습니다.
SHAP (TreeExplainer) 기여도 분석 1:1 맞춤형 폐업 위험 요인 진단기
"환자의 종합 혈액 검사지에서 어떤 수치가 당뇨 위험을 높였고 낮췄는지 보여주듯, 개별 점포의 어떤 지표가 폐업을 유도했는지 정밀 분석합니다."
게임이론 기반의 Shapley Value를 트리 앙상블 모델에 적용하여, 블랙박스 형태의 모델 예측 결과를 각 피처의 정밀한 기여도(log-odds 단위)로 분해 및 시각화(Waterfall 플롯)하였습니다.
PR-AUC (정밀도-재현율 곡선 면적) 극소수 위험 상점(3%) 정밀 탐지율
"서울시 상가 중 실제 폐업하는 곳은 3%에 불과합니다. '아무도 폐업 안 한다'고 억지 부려 97%의 거짓 정확도를 내는 모델 대신, 진짜 위험한 3%를 얼마나 잘 솎아내는지 측정합니다."
극심한 클래스 불균형(Imbalanced Data) 상황에서는 일반적인 Accuracy나 ROC-AUC 지표가 왜곡(Inflation)됩니다. 따라서 소수 클래스인 '폐업 위험 점포'에 대한 정밀도(Precision)와 재현율(Recall) 곡선의 아랫면적을 통해 평가 신뢰성을 증명합니다.
