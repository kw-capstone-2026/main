# 서울시 상권 과포화/폐업 예측 모델 고도화 통합 검증 리포트 (walkthrough.md)

본 문서는 팀원들의 개별 피처 실험(트랙 A~C)을 하나의 강력한 데이터 파이프라인으로 온전히 융합하고, 다중 모형 학습(XGBoost, LightGBM), 소프트 보팅 앙상블, 그리고 설명 가능한 AI(XAI - SHAP) 시뮬레이션까지 성공적으로 구동하여 검증한 종합 보고서입니다.

## 1. 수행한 주요 작업 내역 (Changes Made)

1. **데이터 통합 파이프라인 구축 (`agenttest/run_data_harmonization.py` [NEW])**
   - Teammate 1의 소비 패턴, 아파트 정보, 직장 인구 변수들과 Teammate 3의 집객시설 정보 API를 하나로 모은 **일괄 수집·가공 엔진**을 구현했습니다.
   - 2019Q1부터 2024Q4까지 총 24개 분기에 대해 서울 열린데이터 광장 Open API를 실시간으로 자동 조회하여 병합하고, 결측치를 교정 및 `Float64` 수치형 정렬을 수행했습니다.
   - 상대적 포화 압력을 잡아내는 **7종의 Density 파생 변수** 및 **집객시설 밀도** 변수를 완전하게 도출하여 `final_merged_commercial_data_v5.parquet` 마스터 데이터셋을 빌드했습니다.
2. **단일 모델 비교 실험 루프 (`agenttest/run_unified_model_experiment.py` [NEW])**
   - 구축된 131MB 대용량 마스터셋(512,626행, 126개 열)에 대해 시계열 분할(Train: ~2023년 / Test: 2024년)을 수행했습니다.
   - XGBoost Classifier와 LightGBM Classifier에 각각 팀원들의 최적 복잡도 규제 및 클래스 가중치 파라미터(`scale_pos_weight=33.33`)를 할당하여 교차 평가했습니다.
3. **소프트 보팅 앙상블 설계 (`agenttest/run_ensemble_voting.py` [NEW])**
   - 두 모델이 결합했을 때의 일반화 성능 향상을 위해 가중치 조합별(XGB 0.5:LGB 0.5, XGB 0.3:LGB 0.7 등) Soft Voting Classifier를 구현했습니다.
   - 클래스 불균형에 특화된 정밀 지표인 **PR-AUC (Precision-Recall AUC)** 연산 모듈을 추가하고 결과 리포트(`ensemble_performance_report.txt`)를 내보냈습니다.
4. **설명 가능한 AI (XAI) 도입 (`agenttest/explain_model_shap.py` [NEW])**
   - `shap.TreeExplainer`를 활용하여 글로벌 차원의 피처 영향도(Summary Plot) 및 특정 개별 매장 차원의 로컬 기여도(Waterfall Plot)를 시각화 이미지로 빌드해냈습니다.

## 2. 주요 실험 및 성능 평가 결과 (Validation Results)

### ① XGBoost vs LightGBM 단일 모델 비교

- **XGBoost (AUC: 0.9076, PR-AUC: 0.3135)**:
  - `전년_동기_대비_폐업_증감률`에 과도하게 의존(중요도 39.6%)하였으나, 새롭게 추가한 `집객시설_밀도`가 중요도 9위(2.45%)로 진입하며 예측에 실질 기여함을 증명했습니다.
- **LightGBM (AUC: 0.9089, PR-AUC: 0.3170)**:
  - XGBoost 대비 **더 높은 변별력(AUC +0.0013, PR-AUC +0.0035)**을 보여주었습니다.
  - 특정 피처 편향 없이 `상권_업종_적합도` (4위, 9.52%), `점포당_매출_밀도` (7위, 3.90%), `직장인구_1인당_매출` (8위, 3.71%) 등 밀도와 효율 지표가 전체 Top 10에 대거 진입하여 모델의 견고함을 증명했습니다.

### ② Soft Voting 앙상블 최적 성능 돌파

여러 앙상블 조합을 검증한 결과, **XGBoost 0.3 : LightGBM 0.7** 비율로 결합했을 때 단일 모델의 한계를 극복하는 **최고 성능**을 기록했습니다.

| 모델 구분                      |  ROC-AUC   |   PR-AUC   |  F1-Score  | 비고                             |
| :----------------------------- | :--------: | :--------: | :--------: | :------------------------------- |
| XGBoost 단일                   |   0.9076   |   0.3135   |   0.2379   | 전년 대비 폐업 편향 존재         |
| LightGBM 단일                  |   0.9089   |   0.3170   |   0.2351   | 밀도 기반 피처 고른 활용         |
| **앙상블 (XGB 0.3 : LGB 0.7)** | **0.9089** | **0.3171** | **0.2361** | **[최고 성능]** 일반화 성능 상승 |

> [!TIP]
> 앙상블 모델은 ROC-AUC가 0.9089로 극대화되었을 뿐만 아니라, 소수 클래스인 '폐업/과포화'에 대한 예측 변별력을 평가하는 **PR-AUC 점수 역시 0.3171로 단일 모델을 모두 초과**하며 최고의 탐지력을 보여주었습니다.

## 4. 종합 성과 및 학술적 의의 (Conclusion)

본 통합 검증을 통해 우리 팀의 졸업 작품은 다음 네 가지의 독보적인 강점을 가지게 되었습니다.

1. **파이프라인 무결성 확보**: Teammate 1~3의 성공 피처들을 하나의 API 가동식 파이프라인으로 무결하게 융합했습니다.
2. **공간 결측 해소 및 정합**: 정확한 Open API 매핑 테이블을 구현하여, Teammate 3가 마주한 '구 단위 조인의 정보 0%' 한계점과 Teammate 2의 '과포화 5개 클래스 붕괴'를 완벽히 돌파했습니다.
3. **다중 알고리즘 앙상블**: XGBoost 일변도의 모델 학습에서 벗어나, 리프 중심 트리의 명가인 LightGBM과 Soft Voting을 결합하여 최상위 일반화 지표(AUC 0.9089, PR-AUC 0.3171)를 확보했습니다.
4. **XAI (설명 가능한 AI) 장착**: 모델의 예측 원인을 투명하게 보여주는 글로벌/로컬 SHAP waterfall 시각화를 도입함으로써, **단순 포트폴리오를 넘어 학회 등재가 가능한 수준의 탄탄함**을 실증하였습니다.
