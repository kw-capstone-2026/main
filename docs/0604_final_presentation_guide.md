# 캡스톤 최종 발표 (8분 + 2분 Q&A) 완벽 대비 가이드

**작성일**: 2026-06-04
**상황**: 발표 첫날, 첫 번째 순서
**전략 요약**: 첫 발표의 부담감을 '기준선 제시'의 기회로! 교수님의 3대 피드백을 완벽 방어하며, 데이터 분석팀다운 깊이를 캡처 데모와 다각도 시각화로 뽐내기.

## 1. 교수님 피드백 완벽 방어 핵심 3가지 (반드시 포함)

이 3가지는 발표 중 심사위원(교수님) 귀에 **명확하게 꽂히도록** 발음해야 합니다.

1. **3% 불균형 적극 해결**: "단순히 PR-AUC만 재고 끝내지 않고, 전처리를 최우선 과제로 삼았습니다."
2. **논문 기반의 방법론 (당위성)**: "금융 리스크 관련 최신 논문들에서 입증된 SMOTE, XGBoost/LightGBM, SHAP 기법을 채택했습니다."
3. **치열한 시각화의 흔적**: "저희는 데이터 분석 특화 팀으로서 '왜 이런 결과가 나왔는지'를 다각도의 시각화(밀도, 변수 중요도, 공간 리스크)로 증명했습니다."

---

## 2. 시간 재분배: 데이터 분석 중심의 8분 스크립트 (캡처 데모 반영)

### [0:00 ~ 1:00] 1. 문제 정의 (도입)

- **포커스**: 문제의 심각성 어필
- **스크립트**: "안녕하십니까, 발표를 맡은 OOO입니다. 저희 프로젝트는 단순한 상권 분석을 넘어, 소상공인의 '폐업 위험'을 사전 경고하는 것을 목표로 합니다. 통계에 따르면 폐업률이 급증하고 있지만, 이를 사전에 진단할 시스템은 부재합니다. 폐업을 미리 예측하는 것은 매우 까다롭고 중요한 과제였습니다."

### [1:00 ~ 2:30] 2. 데이터 분석의 난관과 방법론적 근거 (★ 피드백 방어 구간)

- **포커스**: 3% 불균형 발견 및 비용민감학습(scale_pos_weight) 도입 (논문 인용)
- **스크립트**: "데이터 수집 후 탐색적 분석(EDA)을 진행한 결과, 실제 폐업 데이터는 단 **3%에 불과한 극심한 불균형 상태**였습니다. 교수님의 중간 면담 피드백을 깊이 수용하여, 저희는 단순히 성능 지표만 뽑고 타협하지 않았습니다. 이를 근본적으로 해결하기 위해 논문(He & Garcia, 2009)에 근거하여, 트리에 비효율적인 합성 오버샘플링 대신 손실함수에서 직접 불균형을 보정하는 **비용민감 학습(Cost-Sensitive Learning)** 기법을 도입했습니다. 또한 검증된 **XGBoost와 LightGBM 앙상블 기법**을 사용하여 학술적 근거를 바탕으로 예측력을 극대화했습니다."
- **PPT 팁**: 이 장표의 우측 하단에 조그맣게 비용민감학습과 모델링 관련 논문 레퍼런스(예: _He, H., & Garcia, E. A. (2009). Learning from Imbalanced Data_)를 기재하세요.

### [2:30 ~ 5:30] 3. 치열한 고민의 흔적: 시각화 분석 스토리 (★ 가장 중요한 하이라이트)

- **포커스**: 우리가 얼마나 데이터와 씨름했는지, 다각도 시각화 자료를 쏟아내며 증명
- **스크립트**: "저희는 데이터 분석 특화 팀으로서, 결과를 도출하기까지 수많은 시각화를 통해 데이터의 숨겨진 패턴을 추적했습니다.
  1. 먼저, **밀도 분포 시각화**를 통해 정상 상권과 폐업 상권의 데이터 특성이 어떻게 다른지 파악했습니다.
  2. 다음으로, 특정 요인이 폐업에 얼마나 치명적인지 **SHAP 설명 가능 모델 기법(논문 기반)**을 통해 물어봤습니다.
  3. **(그래프 강조하며)** 특히 이 분석을 통해 가장 중요한 **'티핑 포인트(Tipping Point)'**를 발견했습니다. 월 매출 500~700만 원 구간을 기점으로 폐업 위험이 기하급수적으로 폭증한다는 사실을 시각적으로 도출해 냈습니다. 이는 모델이 현실의 경제적 마지노선을 정확히 학습했다는 것을 증명합니다."

### [5:30 ~ 7:00] 4. 최종 구현 결과 및 화면 캡처 리뷰 (★ 데모 대체 파트)

- **포커스**: 분석 결과가 서비스에 어떻게 녹아들었는지 캡처로 임팩트 있게 전달
- **스크립트**: "이러한 정밀한 분석과 모델링 결과를 사용자가 직관적으로 확인할 수 있도록 시스템을 구현했습니다. (캡처 화면 장표) 데모 화면을 캡처한 이 슬라이드를 보시겠습니다. 특정 상권을 검색하면 단순 데이터 나열이 아닌, 앞선 앙상블 모델이 계산한 **정교한 Risk Score(위험도)**가 시각적 경고 형태로 제공됩니다. 앞서 분석한 티핑 포인트 결과도 서비스 로직에 반영되어, 실질적인 인사이트를 제공하도록 설계했습니다."

### [7:00 ~ 8:00] 5. 실험 결과, 한계점 및 향후 개선 방향

- **포커스**: 성능 입증 및 솔직한 피드백
- **스크립트**: "결론적으로 전처리를 적극 수행한 결과, 폐업 예측을 나타내는 PR-AUC 등의 지표가 비약적으로 상승했습니다. 하지만 거시 경제 지표(금리 폭등 등)를 실시간 반영하지 못한 점은 한계로 남습니다. 향후 공공 API 연동을 통해 파이프라인을 고도화할 계획입니다. 이상으로 발표를 마치겠습니다."

2. **시간 8분은 칼같이 지키세요.**

## 4. 질의응답(Q&A) 2분

어떤 질문이 나와도 '데이터'와 '논문'을 핑계로

**Q1. 데이터 불균형(3%)이 심했는데 과적합(Overfitting) 발생 안 했나요? SMOTE 같은 오버샘플링을 쓰지 않은 이유는요?**

- **A**: "네, 51만 행이라는 대규모 데이터에서 SMOTE와 같은 오버샘플링 기법은 컴퓨팅 비용이 매우 높고, 트리 앙상블 모델에서는 확률 순위(AUC) 개선에 한계가 있다는 최신 논문(He & Garcia)의 지적을 수용했습니다. 그래서 가짜 데이터를 생성하는 대신, 손실함수에서 소수 클래스에 페널티를 강하게 부여하는 **비용민감 학습(Cost-Sensitive Learning)**을 사용하여 원본 데이터의 무결성을 유지하면서 과적합을 방지했습니다. 교차 검증(Cross-Validation) 결과에서도 안정적인 성능을 확인했습니다."

**Q2. 티핑 포인트(매출 500~700)라는 게 정말 믿을 수 있는 수치인가요?**

- **A**: "SHAP Value라는 수학적 기여도 산출 방식(논문 기반)을 통해 도출된 데이터 기반의 팩트입니다. 500~700만 원이라는 수치는 소상공인의 임대료, 인건비 등 평균 고정비 마지노선과 현실적으로도 매우 일치하여 저희도 모델의 신뢰성을 확신하게 되었습니다."

**Q3. 왜 다른 예측 모델 말고 XGB/LGBM 앙상블을 썼나요?**

- **A**: "정형 데이터(테이블형 데이터)와 극심한 불균형 분류 문제에서는 딥러닝보다 트리 기반 앙상블 기법이 더 우수하다는 다수의 금융/위험 예측 논문들을 참고했습니다. 실제로 단일 모델보다 앙상블을 했을 때 예측력이 유의미하게 상승했습니다."
