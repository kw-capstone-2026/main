## 실험 배경

### 문제 인식

기존 상권 분석 데이터에 **DS5 생활인구 데이터** (시간대별 유동인구)를 추가하면 모델 성능이 향상될 것으로 기대

### DS5 데이터란?

| 항목            | 설명                            |
| --------------- | ------------------------------- |
| **데이터 소스** | 서울시 DS5 생활인구 (격자 단위) |
| **기간**        | 2023Q1 ~ 2026Q2 (14분기)        |
| **변수**        | 시간대별 유동인구 10개          |
| **처리**        | 격자 → 상권 단위 집계           |

### DS5 변수 목록

`1. 주중_오전_avg (06-12시) 2. 주중_점심_avg (12-14시) 3. 주중_저녁_avg (17-21시) 4. 주중_야간_avg (21-06시) 5. 주말_주간_avg (06-21시) 6. 주말_야간_avg (21-06시) 7. 주야간비율 8. population_slope (인구 증가 추세) 9. population_entropy (인구 분산도) 10. 평균인구`

## 🔍 원인 분석

#### 1. 심각한 클래스 불균형

📊 Train 데이터 분포
├─ 정상: 6,288개 (99.92%)
└─ 과포화: 5개 (0.08%) ⚠️

📊 Test 데이터 분포
├─ 정상: 6,271개 (99.87%)
└─ 과포화: 8개 (0.13%) ⚠️

**문제점**

- 과포화 케이스가 극히 적어 패턴 학습 불가
- 모델이 "모두 정상"으로 예측하는 전략 선택
- DS5 정보를 활용할 기회 자체가 없음

#### 2. 낮은 DS5 매칭률

📊 DS5 데이터 커버리지
├─ DS5 값 있음: 1,598행 (12.7%)
└─ DS5 null: 10,974행 (87.3%) ⚠️

**분기별 매칭 현황**

| 분기   | 전체  | DS5 매칭 | 매칭률 |
| ------ | ----- | -------- | ------ |
| 2023Q1 | 1,573 | 201      | 12.8%  |
| 2023Q2 | 1,574 | 201      | 12.8%  |
| 2023Q3 | 1,574 | 200      | 12.7%  |
| 2023Q4 | 1,572 | 200      | 12.7%  |
| 2024Q1 | 1,570 | 198      | 12.6%  |
| 2024Q2 | 1,571 | 200      | 12.7%  |
| 2024Q3 | 1,568 | 199      | 12.7%  |
| 2024Q4 | 1,570 | 199      | 12.7%  |

**문제점**

- 87%의 데이터에서 DS5 정보 없음
- XGBoost가 null 처리 가능하나, 정보량 부족
- 패턴 학습에 필요한 최소 샘플 수 미달

#### 3. 강한 기존 Feature 존재

**Baseline 모델 이미 높은 성능 달성**

- AUC: 0.9964
- Accuracy: 0.9987

**강력한 예측 변수들**

- 프랜차이즈*점포*수 (18.2%)
- 상권*전체점포*수 (14.0%)
- 점포\_수 (13.6%)

#### **시사점**

- 기존 Feature만으로 충분한 예측력 확보
- DS5가 제공하는 추가 정보의 marginal value 낮음
- 모델이 DS5를 noise로 판단하여 배제
