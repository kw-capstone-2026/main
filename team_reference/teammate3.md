#### 0521 집객시설 변수 추가 실험 결과 보고서

**모델** : XGBoost 베이스라인 (기존 설정 유지) + LightGBM 비교 실험
**추가 데이터** : 서울시 상권분석서비스(집객시설-상권) CSV
**추가 변수** :

- `집객시설_수` (단순 변수)
- `집객시설_밀도` = 집객시설*수 / (상권*전체점포\_수 + 1) (파생변수)

**조인 키** : 기준*년분기*코드 + 상권\_코드

---

**1. 실험 개요**
베이스라인 모델 (XGBoost, AUC 0.9040) 에 서울시 상권분석서비스(집객시설-상권) 데이터를 추가하고, XGBoost와 LightGBM 두 모델을 비교 실험하였습니다.

**2. 추가한 변수**

- `집객시설_수` (단순 변수): 상권 내 집객시설 총 수 (관공서, 은행, 병원, 학교, 백화점 등)
- `집객시설_밀도` (파생변수): 집객시설*수 / (상권*전체점포\_수 + 1) → 점포 수 대비 집객시설 비율

**3. 데이터 출처 및 병합 방식**

- 출처: 서울 열린데이터 광장 - 서울시 상권분석서비스 (집객시설-상권)
- 조인 키: 기준*년분기*코드 + 상권\_코드 (Left Join)
- 결측치 처리: 0으로 대체
- 적용 파일: `src/feature_merger.py` 병합 로직 추가 → `src/models/train_baseline.py` feature_cols 추가

**4. 실험 결과**

| 모델                | AUC        | Accuracy | 변화        |
| ------------------- | ---------- | -------- | ----------- |
| XGBoost 베이스라인  | 0.9040     | 0.8219   | 기준        |
| XGBoost + 집객시설  | 0.9043     | 0.8321   | +0.0003     |
| LightGBM + 집객시설 | **0.9058** | 0.8288   | **+0.0018** |

**5. 피처 중요도**

**XGBoost:**

| 순위 | 변수명                     | 중요도   |
| ---- | -------------------------- | -------- |
| 1    | 전년*동기*대비*폐업*증감률 | 67.9%    |
| 2    | 점포당*평균*매출           | 8.1%     |
| 3    | 상권*전체점포*수           | 5.6%     |
| 5    | **집객시설\_밀도**         | **2.4%** |
| 7    | **집객시설\_수**           | **1.9%** |

**LightGBM:**

| 순위 | 변수명                     | 중요도  |
| ---- | -------------------------- | ------- |
| 1    | 점포당*평균*매출           | 845     |
| 4    | 전년*동기*대비*폐업*증감률 | 521     |
| 9    | **집객시설\_밀도**         | **266** |
| 10   | **집객시설\_수**           | **231** |

**6. 분석 결론**
집객시설*수와 집객시설*밀도 두 변수 추가 후 XGBoost AUC가 0.0003 소폭 상승하였으며, LightGBM 적용 시 AUC 0.9058로 베이스라인 대비 0.0018 상승하였습니다.

두 모델 모두 집객시설 관련 변수가 Top 10 피처 중요도 안에 진입하였으며, 집객시설*밀도(파생변수)가 집객시설*수보다 일관되게 예측력이 높게 나타났습니다.

이는 단순 시설 수보다 상권 규모 대비 집객시설 비율이 과포화 예측에 더 유의미함을 시사합니다. 다만 집객시설 데이터가 연간 1회 업데이트되어 분기별 변화를 반영하지 못하는 한계가 있습니다.
