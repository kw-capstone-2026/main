카드는 두 줄로 구성함.

1. 등급 문장: 위험 등급별 고정 문장

### 1줄: 이유 문장 만드는 법

```
{1위 구절}이 위험을 가장 크게 {높였/낮췄}고, {2위 구절}{도/은} 위험을 {높였/낮췄}습니다.
```

- 높였/낮췄: shapValue가 양수면 높였, 음수면 낮췄
- 2위 조사: 1위와 방향이 같으면 "도", 다르면 "은"
- 구절은 모두 받침으로 끝나서 조사는 항상 "이", "은", "도"로 고정해도 됨

### 2줄: 등급 문장

| 등급 | 문장                                                                                                                    |
| ---- | ----------------------------------------------------------------------------------------------------------------------- |
| 위험 | 위험 등급은 실제 과포화 비율이 평균의 약 10배인 구간입니다. 최근 개폐업 흐름과 매출 추이를 먼저 확인해 보시길 권합니다. |
| 주의 | 주의 등급은 실제 과포화 비율이 평균의 약 2배인 구간입니다. 다음 분기 흐름을 함께 지켜볼 필요가 있습니다.                |
| 안전 | 안전 등급은 실제 과포화 비율이 평균보다 낮은 구간입니다. 다만 이번 분기 기준 진단이라 흐름은 바뀔 수 있습니다.          |

숫자 근거: 2024년 4분기 검증 결과 (위험 9.9배, 주의 2.3배, 안전 0.2배)

## 변수별 구절

shapValue 방향에 따라 구절을 고름. 방향과 값의 관계는 2024년 4분기 전체 블록에서 확인함 (예: 점포당 평균 매출은 낮을수록 SHAP이 양수).

| name                       | 위험을 높일 때 (shapValue > 0)        | 위험을 낮출 때 (shapValue < 0)                                                                                                                   |
| -------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 전년*동기*대비*폐업*증감률 | 작년 같은 분기보다 폐업이 늘어난 것   | 값 < 0: 작년 같은 분기보다 폐업이 줄어든 것 / 값 = 0: 작년 같은 분기보다 폐업이 늘지 않은 것 / 값 > 0: 작년 같은 분기보다 폐업 증가 폭이 작은 것 |
| 점포당*평균*매출           | 점포당 평균 매출이 낮은 것            | 점포당 평균 매출이 높은 것                                                                                                                       |
| 폐업\_률\_y                | 상권 평균 폐업률이 높은 것            | 상권 평균 폐업률이 낮은 것                                                                                                                       |
| 당월*매출*금액             | 이번 분기 매출 규모가 큰 것           | 이번 분기 매출 규모가 작은 것                                                                                                                    |
| 당월*매출*건수             | 이번 분기 결제 건수가 적은 것         | 이번 분기 결제 건수가 많은 것                                                                                                                    |
| 운영*영업*개월\_평균       | 상권 점포들의 평균 영업기간이 짧은 것 | 상권 점포들의 평균 영업기간이 긴 것                                                                                                              |
| 집객시설\_밀도             | 주변 집객시설이 적은 것               | 주변 집객시설이 많은 것                                                                                                                          |
| 그 외 변수                 | {label} 수준                          | {label} 수준                                                                                                                                     |

- 4분기 블록에서 1위 이유로 나오는 변수는 위 표의 앞 4개뿐임 (작년 대비 폐업 증감 70.9%, 점포당 평균 매출 24.6%, 상권 평균 폐업률 4.5%, 이번 분기 매출액 일부).
- "그 외 변수"는 방향을 단정하기 어려운 변수라 값의 높고 낮음을 말하지 않음. {label}에는 화면에 보이는 표시명을 그대로 넣으면 됨.
- "이번 분기 매출 규모가 큰 것"이 위험을 높이는 건 직관과 다르게 보일 수 있음. 매출이 큰 상권일수록 점포가 많고 개폐업도 잦은 경향 때문이며, 질문이 나오면 이렇게 설명하면 됨.
