# 정답(라벨)과 데이터 누수 점검

> 라벨은 바꾸지 않았음. 파케이에 있는 `과포화_위험_여부`를 그대로 쓰고, 입력 변수와의 관계만 측정함.
> 라벨을 만든 코드는 저장소에서 찾지 못했음. 아래는 데이터로 추정한 결과이고 확정이 아님.

## 한 줄 요약

정답은 **"이번 분기에 그 업종 가게가 많이 문 닫았고(폐업률), 가게당 매출이 낮은 곳"** 과 거의 같음. 그런데 모델의 1위 변수 `전년_동기_대비_폐업_증감률`이 **이번 분기 폐업 수**로 계산돼 있어서, 모델이 "미래를 예측"했다기보다 **"이번 분기 상태를 진단"** 한 것에 가까움. 교수님이 데이터 누수를 물으면 이 점을 솔직하게 설명해야 함.

## 근거

1. `전년_동기_대비_폐업_증감률` = (이번 분기 폐업 점포 수 − 작년 같은 분기 폐업 점포 수) ÷ (작년 같은 분기 폐업 점포 수 + 1) 임. 재계산 값과 **100.0%** 일치함 → 이번 분기 폐업 정보가 입력에 들어 있음.
2. 2024년에서 변수 하나만으로 정답을 맞힌 정도 (ROC-AUC, 0.5 = 찍기, 1.0 = 완벽):

| 변수 | ROC-AUC |
|---|---:|
| 폐업_률_x (이번 분기, 업종 단위, 모델 입력 아님) | 0.918 |
| 폐업_점포_수 (이번 분기, 모델 입력 아님) | 0.883 |
| 전년_동기_대비_폐업_증감률 (모델 입력) | 0.801 |
| 점포당_평균_매출 (모델 입력, 낮을수록 위험으로 뒤집음) | 0.685 |
| 폐업_률_y (모델 입력, 상권 단위) | 0.569 |
| 참고: 우리 모델 (앙상블) | 0.909 |

3. 이번 분기 폐업률(`폐업_률_x`)이 0인 블록 66,817개 중 정답=1은 **0.0%**. 정답=1 블록의 **100.0%**는 이번 분기 폐업이 있었음.
4. 이번 분기 폐업률·매출 등 5개 변수로 만든 아주 단순한 규칙(깊이 3 결정트리)이 2024년에서 ROC-AUC **0.946** 를 냄 (우리 모델 0.909보다 높음). 규칙:

```
|--- 폐업_률_x <= 2.5
|   |--- class: 0
|--- 폐업_률_x >  2.5
|   |--- 점포당_평균_매출 <= 2738902.0
|   |   |--- 점포당_평균_매출 <= 169145.1
|   |   |   |--- class: 1
|   |   |--- 점포당_평균_매출 >  169145.1
|   |   |   |--- class: 0
|   |--- 점포당_평균_매출 >  2738902.0
|   |   |--- 점포당_평균_매출 <= 20157454.0
|   |   |   |--- class: 0
|   |   |--- 점포당_평균_매출 >  20157454.0
|   |   |   |--- class: 0
```

## 발표·시연에서 어떻게 말할지 (제안)

- "폐업 예측"보다 **"상권 과포화 위험 진단"** 이라고 부르는 것이 정확함.
- "2019~2023년으로 학습한 모델이 처음 보는 2024년에서도 진단 성능(ROC-AUC 0.909)을 유지함"은 사실이므로 말해도 됨.
- "다음 분기 폐업을 미리 맞힌다"는 표현은 쓰지 말 것 (현재 검증되지 않음).
- 확실히 하려면: 라벨 정의를 만든 팀원에게 확인하거나, 이번 분기 입력으로 **다음 분기** 정답을 맞히는 실험을 추가해야 함 (모델 재학습 필요, 이번 작업 범위 밖).
